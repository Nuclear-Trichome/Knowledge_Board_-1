California ID Barcode Checker

Scan the PDF417 barcode to calculate age and check data consistency. This does not authenticate an ID or confirm DMV issuance.

Connectivity: This CDN edition loads the decoder JavaScript and WebAssembly from jsDelivr. An internet connection is needed to load them; camera frames and ID data are processed in the browser, not sent to our server. For strictly offline use, host both decoder files locally. iPhone Safari camera access generally requires HTTPS; opening this file from Files may not grant camera access.
